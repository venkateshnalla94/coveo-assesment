# Architecture Diagrams: Major Flows

Task-oriented companion to `outputs/architecture/*.md` (the maintained, per-section current-state
snapshot regenerated by `architecture-docs-agent`). These five files each answer one end-to-end
question — "how does X actually talk to Coveo" — by pulling the relevant pieces from that snapshot
plus the live route/hook source into one place, with a sequence diagram per flow.

If code changes, `outputs/architecture/*.md` is the source of truth to re-derive these from; these
files are not regenerated automatically.

## Coveo endpoints at a glance

| Flow | Auth credential | Host / path family | Protocol |
| --- | --- | --- | --- |
| Search + suggestions, catalog facets/sort/pagination | Search token (browser) or `NEXT_PUBLIC_COVEO_ANONYMOUS_SEARCH_API_KEY` | `@coveo/headless/commerce` engine → Commerce API (endpoint auto-resolved from `organizationId`) | Headless SDK, REST under the hood |
| Search token minting | `COVEO_AUTHENTICATED_SEARCH_API_KEY` (server-only) | `https://{orgId}.org.coveo.com/rest/search/v2/token` (falls back to `/rest/search/token`) | REST, JSON |
| Generative Answer (RGA) | `COVEO_PLATFORM_API_KEY` (server-only) | Coveo Search API `platform-eu.cloud.coveo.com/rest/search/v2` + `.../machinelearning/streaming/{streamId}` | REST + `text/event-stream` |
| Content search (trending rail, `/blog`, `/blog/[id]`) | `COVEO_PLATFORM_API_KEY` (server-only) | Coveo Search API, same base as RGA | REST, JSON |
| Conversational agent | `COVEO_PLATFORM_API_KEY` + `COVEO_SEARCH_AGENT_ID` (server-only) | `https://{orgId}.org.coveo.com/api/v1/organizations/{orgId}/agents/{agentId}/answer` \| `/follow-up` | REST request, AG-UI `text/event-stream` response |
